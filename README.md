# Matthew Koo — academic website

Personal academic website of Matthew Koo, Ph.D. Candidate in Political
Science at Yale University. Built with [Hugo](https://gohugo.io/) and
deployed to GitHub Pages via GitHub Actions.

- **Edit content:** see [UPDATING.md](UPDATING.md) — most changes are a
  single YAML or Markdown edit, doable directly on GitHub in the browser.
- **Local preview:** install Hugo (extended), then run `hugo server` in the
  repo root and open <http://localhost:1313/>.
- **Deployment:** every push to `main` triggers the workflow in
  `.github/workflows/deploy.yml`, which builds the site and publishes it to
  GitHub Pages.
